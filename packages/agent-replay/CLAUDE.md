# packages/agent-replay

화면 기록 플러그인 (rrweb). **코어 에이전트와 기준이 다르다** — 여기는 무거운
의존성이 허용되지만, 그 대가로 반드시 옵셔널이어야 한다.

## 왜 별도 패키지인가

rrweb은 gzip으로도 코어 에이전트(~2.5KB)보다 수십 배 크다. 코어에 넣으면
"의존성 0 / 수 KB" 계약이 깨지고, 콘솔·네트워크만 필요한 팀이 비용을 문다.
**이 패키지를 코어로 합치자는 제안은 거절할 것** (`docs/decisions.md`).

## 계약

- 코어의 `agent.emit`으로 이벤트를 싣는다 — 자체 전송을 만들지 말 것.
  세션·연결이 하나로 유지돼야 타임라인 순서가 보장되고 캡처 파일에도 함께 들어간다
- 코어의 게이팅을 따른다: `agent.enabled === false`면 아무것도 하지 않는다
- 입력 마스킹은 기본 켜짐 — DOM 기록은 화면의 모든 텍스트를 수집한다
- 프로토콜의 `screen.format`은 열려 있다 (현재 `'rrweb'`). 다른 캡처 방식이
  같은 슬롯을 쓸 수 있어야 하므로 프로토콜에 rrweb 타입을 새기지 말 것

## 테스트

rrweb은 jsdom에서 완전히 동작하지 않는다 — `vi.mock('rrweb')`으로 계약만 검증한다
(emit 콜백 전달, 게이팅, 마스킹 기본값, stop 해제). 실동작은 `examples/demo`로.
