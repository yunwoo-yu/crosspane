`--headed` 실창 모드 — 캡처 없는 0ms 렌더링

- 브라우저들을 진짜 창으로 띄운다 — 스크린샷/스트림 파이프라인 없이 실물이라 렌더링 지연 0
- **리더(Chromium) 창을 직접 조작**하면 클릭/휠/키 입력이 나머지 엔진 창에 미러링됨
  (리더 페이지에 캡처 스크립트 주입 → sendBeacon 릴레이 → 발신 엔진 제외 재생)
- 대시보드는 그대로 콘솔/네트워크/diff 수집 패널로 동작
- 참고: 한 창 안에 3개 엔진을 "직접" 임베드하는 것은 브라우저 아키텍처상 불가능
  (Chrome은 Blink로만 렌더링, Gecko는 데스크톱 임베드 API 없음) — 실창 모드가
  물리적으로 가능한 최저 지연이다
